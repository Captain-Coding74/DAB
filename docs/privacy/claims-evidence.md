# Public claims and their evidence

Every product claim on the landing page (`/welcome`) and every privacy note inside the app, with the code and tests that back it. Thai law treats an advertiser who cites facts it cannot prove as knowing the claim was false (Consumer Protection Act s.28), and a privacy notice that contradicts the product is itself evidence against the operator. Keep this file current: when copy changes, update the row; when a row has no evidence, fix the copy or add the evidence.

**About "Lane A".** v21.30 was built in two parallel streams. This file was written in the stream that changed the copy, share links, AI labels, legal pages and licences. The other stream ("Lane A") built the behaviour several claims rely on: AI minimisation and wider personal-data detection (A1), opt-in saving, school attestation and retention (A2), the `/account` page and privacy-request log (A3), click-wrap and the traffic log (A4), and security hardening (A5). A claim marked **Lane A** was not yet backed by code in this stream; the lane-A files and tests named are as they stood when this was written. **After the merge, check every Lane A row** and delete the flag when its test passes.

Tests named "routes", "shares" and so on are `backend/src/<name>.test.js`; the frontend's are `frontend/src/lib/<name>.test.js`.
