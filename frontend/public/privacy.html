3. What we collect

Without an account (try mode)

Your file is read in the server's memory, analysed with statistics only and discarded as soon as the result is sent back. It is not stored, and nothing from it goes to the AI. A PDF or Excel export made without an account is built the same way and not kept. What we keep:

  • a telemetry record of the file's shape: file type, size, the number of rows and columns, column types, how it was read (such as text encoding and separator), category tags from a fixed list (such as “date” or “customer”) and a guess at the kind of file (such as “restaurant” or “payroll”) — never the file name, column names or any values. Tapping a sample file records the same, naming the sample;
  • a traffic-log entry — your IP address, the time and the event (for example “analyze”) — kept for 90 days;
  • the request log on our host (see Logs below).

Your account

  • Your username and password. The password is stored only as a bcrypt hash.
  • Your email address, if you give one. It is optional and never verified, and we do not use it to send you anything. Only you can see it — not workspace members or dataset collaborators.
  • Your acceptance of the Terms and this notice: the version you accepted, the time and your IP address.
  • Sign-in records: the time of your last sign-in; a one-way hash of each session's refresh token, removed after it expires or you sign out; and a security audit log of sign-up, sign-in and sign-out-everywhere events with IP address and time.

Analyses (your History)

When you are signed in, each analysis is saved: the file name, your question, the AI report text, the numbers of rows and columns, column names, per-column statistics including the most frequent values (with detected identifiers such as citizen ID, phone and card numbers masked), chart data and the quality score. No IP address is stored with it.

Saved datasets

Your original file is stored only if you press “Save dataset” — an opt-in step with its own notice. Hypothesis tests and file versions need a saved dataset. If a file looks like a class roster (School Edition), saving also requires you to confirm “I am authorised by my school to process these students' data”. With the file we keep its name, size, column statistics, versions, tags and the access you grant to other users. Stored files are encrypted at rest (AES-256-GCM) when the operator has enabled it. The original is kept exactly as you uploaded it: masking applies to what DAB shows, stores as statistics and sends to the AI, not to your file.

Chat and the deep-dive agent

Your questions and the AI's answers are stored with the analysis they belong to.

Share links

For each link you create we keep a random token, a title (by default the generic “Analysis report”, never the file name), the expiry date (1, 7, 30 or 90 days), the optional password as a bcrypt hash, and a view count. Anyone with the link can see the AI text, column names, statistics and chart until it expires. The page leaves out the file name and the most frequent values of columns detected as personal data, and asks search engines not to index it. Revoking a link deletes it.

Workspaces and collaboration

If you create or join a workspace we keep its name, its branding settings, and its members and their roles. Members see each other's usernames, not email addresses. When you share a dataset with another user by username, they get the role you choose (viewer or editor). Comments (including @mentions), notifications and the activity feed (for example “uploaded a dataset”) are stored and shown to people with access to that workspace or dataset.

Logs

  • Traffic log, required by section 26 of the Computer-Related Crime Act B.E. 2550 (2007): the event, your user id if you are signed in, IP address, time and an optional reference, for sign-up, sign-in, sign-out, analyses, dataset uploads, exports, share-link creation and views, downloads of your data and account deletion. Kept for 90 days, then deleted. No feature of DAB shows it to anyone; we hand it over only to an official entitled to it by law.
  • Request log: for each request the server records your IP address, the method, the address requested (with share-link tokens removed) and the result code; error records may also include your user id. These logs are kept by our hosting provider for as long as its log retention allows.
  • Rate-limit counters keyed by IP address or user id, kept for up to 15 minutes.

Telemetry

For each analysis, dataset upload and sample-file tap we keep the shape-only record described under try mode. When you are signed in it is linked to your user id. Kept for 395 days. Only the operator can read the aggregate summary.

In your browser

No cookies. Six small localStorage entries for your session, username, theme, language and the app tour — listed in the Storage notice.

3. ข้อมูลที่เราเก็บ

เมื่อไม่มีบัญชี (โหมดลองใช้)

ไฟล์ของคุณถูกอ่านในหน่วยความจำของเซิร์ฟเวอร์ วิเคราะห์ด้วยสถิติล้วน และถูกทิ้งทันทีที่ส่งผลลัพธ์กลับไป ไม่มีการจัดเก็บ และไม่มีข้อมูลใดจากไฟล์ถูกส่งให้ AI การส่งออกรายงาน PDF หรือ Excel โดยไม่มีบัญชีก็ทำแบบเดียวกันและไม่ถูกเก็บไว้ สิ่งที่เราเก็บไว้มีเพียง:

  • บันทึก telemetry ที่บอกรูปทรงของไฟล์: ประเภทไฟล์ ขนาด จำนวนแถวและคอลัมน์ ชนิดของคอลัมน์ วิธีที่ใช้อ่านไฟล์ (เช่น การเข้ารหัสข้อความและตัวคั่น) แท็กหมวดคอลัมน์จากรายการที่กำหนดไว้ (เช่น “date” หรือ “customer”) และการคาดเดาประเภทไฟล์ (เช่น ร้านอาหาร หรือเงินเดือน) — ไม่มีชื่อไฟล์ ชื่อคอลัมน์ หรือค่าข้อมูลใด ๆ การแตะไฟล์ตัวอย่างก็บันทึกแบบเดียวกัน โดยระบุว่าเป็นไฟล์ตัวอย่างใด
  • บันทึกข้อมูลจราจรทางคอมพิวเตอร์ — หมายเลข IP เวลา และเหตุการณ์ (เช่น “analyze”) เก็บไว้ 90 วัน
  • บันทึกคำขอ (request log) ที่ผู้ให้บริการโฮสติ้งของเรา (ดูหัวข้อบันทึกด้านล่าง)

บัญชีของคุณ

  • ชื่อผู้ใช้และรหัสผ่าน โดยรหัสผ่านถูกเก็บในรูปค่าแฮช bcrypt เท่านั้น
  • อีเมล หากคุณให้ไว้ ซึ่งไม่บังคับและไม่มีการยืนยัน และเราไม่ใช้อีเมลนี้ส่งสิ่งใดถึงคุณ มีเพียงคุณที่เห็นอีเมลนี้ — สมาชิกพื้นที่ทำงานและผู้ร่วมใช้ชุดข้อมูลมองไม่เห็น
  • การยอมรับข้อกำหนดการใช้งานและประกาศนี้: ฉบับที่คุณยอมรับ เวลา และหมายเลข IP
  • บันทึกการเข้าสู่ระบบ: เวลาที่เข้าสู่ระบบครั้งล่าสุด ค่าแฮชทางเดียวของ refresh token ของแต่ละเซสชัน ซึ่งถูกลบเมื่อหมดอายุหรือเมื่อคุณออกจากระบบ และบันทึกตรวจสอบด้านความปลอดภัย (audit log) ของการสมัคร การเข้าสู่ระบบ และการออกจากระบบทุกอุปกรณ์ พร้อมหมายเลข IP และเวลา

ผลวิเคราะห์ (ประวัติ)

เมื่อเข้าสู่ระบบ ผลวิเคราะห์แต่ละครั้งจะถูกบันทึก ได้แก่ ชื่อไฟล์ คำถามของคุณ ข้อความรายงานจาก AI จำนวนแถวและคอลัมน์ ชื่อคอลัมน์ ค่าสถิติรายคอลัมน์รวมถึงค่าที่พบบ่อยที่สุด (โดยปิดบังตัวระบุตัวตนที่ตรวจพบ เช่น เลขบัตรประชาชน เบอร์โทร และเลขบัตรเครดิต/เดบิต) ข้อมูลกราฟ และคะแนนคุณภาพ โดยไม่มีการเก็บหมายเลข IP ไว้กับผลวิเคราะห์

7. AI analysis by Anthropic

AI features are provided by Anthropic PBC, a company in the United States, through its Claude API. Anthropic is the only third party that receives content from your files and questions.

  • Who triggers it: only signed-in users. Try mode never sends anything to the AI.
  • What is sent: your question; the numbers of rows and columns; column names; summary statistics; the most frequent values of columns not detected as personal data; correlations and forecasts; the insight sentences DAB computed; and, in chat, the conversation so far.
  • What is not sent: the rows of your file — Analyze, chat, the deep-dive agent and fix suggestions send no raw rows; any value from a column detected as personal data — only its column name and the kind of data (for example “phone”); your file name, username, email address or IP address.

  • Switching it off: tick “Statistics only — don't send to AI” when you upload, or, as the owner of a saved dataset, turn off its AI switch. Nothing from that file or dataset is then sent, and AI features refuse to run on it. You still get every statistic.
  • Anthropic's terms: Anthropic handles this content under its commercial terms and data-processing terms, which do not allow it to train its models on it. It may keep the content for a limited time under its own retention policy.
  • AI can be wrong. AI text is labelled “AI-generated — may be wrong. Check it before you rely on it.” in the app, on share pages and in PDF and Excel exports, which also carry an ai_generated flag.
  • Daily limit: DAB has a global daily budget of AI calls. When it is used up you still get the statistics, without an AI report, until the next day.

10. Security

  • The site is served over HTTPS (TLS), provided by our hosting provider.
  • Passwords are stored as bcrypt hashes. Sessions use short-lived tokens: 15 minutes, renewed by a 7-day refresh token that changes on every use and is stored on the server only as a hash.
  • Sign-in and other requests are rate-limited. Uploads are limited in size and checked by their content, not just their file extension.
  • Saved files are encrypted at rest (AES-256-GCM) when the operator has enabled it.
  • Strict browser security rules apply, and DAB loads no scripts, fonts or other resources from third parties.

No system is perfectly secure. We work to protect your data but cannot guarantee that it will never be lost, changed or accessed without permission.

  • School Edition: teachers may upload their students' records for their school.
